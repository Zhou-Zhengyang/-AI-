# 前端子代理

## 职责

把后端五个接口做成一个能演示的页面。范围是 `web/`。

## 页面只有一个

不做多页、不做设置页、不做主题切换。一屏解决所有事。

布局三块，从左到右。

| 区域 | 内容 |
|---|---|
| 主区 | 对话气泡，每条带判定颜色 |
| 右栏上 | 账户快照：可用余额、卡片状态、持仓合计 |
| 右栏下 | 最近审计记录，显示序号与链校验 |

## 交互约定

输入框回车发送，Shift 加回车换行。

黄色判定时，气泡下方出现确认卡片，两个按钮：确认、取消。

红色判定时，气泡显示命中的规则，不给确认按钮。

绿色判定时，直接显示执行结果。

审计列表每次对话后自动刷新，显示最近十条。

## 数据来源

前端不做任何业务计算。

判定颜色从后端拿，不要自己再算一遍。

金额从后端拿的是分，展示时除一百，保留两位。

状态每次操作后重新拉，不缓存。

## 视觉要求

颜色只有三种含义：绿可执行、黄需确认、红拦截。不要用颜色表达装饰。

字号三档：标题 20px、正文 14px、辅助 12px。

间距用 8 的倍数。

不用阴影做层级，用边框与留白。

## 不许做

不许在前端判断业务规则。

不许把后端返回的原始 JSON 直接渲染给用户看。

不许出现 `undefined`、`[object Object]`、内部字段名。

不许加动画。答辩时动画会拖慢演示节奏。

## 交付前自检

```powershell
cd web
npm run build
```

构建通过后，用浏览器打开，发三条消息：一条绿的、一条黄的、一条红的，三条都要显示正确。
