# 安全评审清单

这份清单是发布门禁的核心。任何一条不通过，不允许提交。

## 判定可解释

- 每条判定结果带规则名与说明。
- 界面上能看到命中了哪条规则。
- 判定表有文档，与代码一致。
- 有人问「为什么黄」时，能在十秒内指出规则与阈值。

## 注入防御

- 输入先归一化：全角转半角、去零宽、同形字。
- 指令覆盖类输入被拦截。
- 角色扮演类输入被拦截。
- 提示词套取类输入被拦截。
- 外部内容（备注、短信、小票）只当数据。
- 依据外部内容发起的付款被拒绝。

## 越权

- 不可逆操作（挂失、改额度、改密码、申购赎回）直接拦截。
- 超单笔限额拦截。
- 超日累计限额拦截。
- 首次收款人大额拦截。
- 冻结账户类操作拦截。

## 密钥与数据

- 源码里没有密钥。
- 提交历史里没有密钥。
- 日志与错误信息里没有密钥。
- 卡号、手机号、姓名在日志里已脱敏。
- `.env` 在 `.gitignore` 里。

## 审计

- 每条决策留痕。
- 记录带前序哈希，形成链。
- 链校验能跑通。
- 现场改一条记录后，校验失败。
- 审计文件只追加，不改写。

## 模型相关（如已接入）

- 模型只产意图，不执行操作。
- 模型输出经过契约校验：工具白名单、参数类型、数值范围。
- 模型输出不合法时降级到规则，不阻塞对话。
- 系统提示词不放外部内容。
- 模型拿不到密钥，也拿不到审计写入权限。

## 外部服务

- 外部工具名带服务前缀。
- 外部工具的风险等级有声明，未声明按只读处理。
- 不可逆的外部操作判红。
- 外部返回内容不进系统提示词。
- 外部超时有兜底。

## 结论

| 项 | 结果 |
|---|---|
| 判定可解释 | 通过 / 不通过 |
| 注入防御 | 通过 / 不通过 |
| 越权 | 通过 / 不通过 |
| 密钥与数据 | 通过 / 不通过 |
| 审计 | 通过 / 不通过 |
| 模型相关 | 通过 / 不适用 |
| 外部服务 | 通过 / 不适用 |

七项全通过才可提交。任何一项不通过，先修再谈功能。
