# 代码评审清单

逐条勾，勾不上就写原因。

## 结构

- 目录与 `docs/03-架构与分层.md` 的分层一致。
- 业务逻辑在运行时目录，没有跑进前端。
- 一个文件只做一件事，文件名能说清这件事。
- 没有超过两百行的函数。

## 金额

- 金额全部是整数分。
- 没有浮点参与运算。
- 展示层统一除一百并保留两位。
- 中文金额解析有对应用例。

## 判定

- 每条判定返回命中规则名与说明。
- 只读操作判绿。
- 不可逆操作判红。
- 阈值集中定义，没有散落在各处。

## 确认

- 令牌绑定会话、工具、参数摘要、有效期。
- 令牌一次性，用过即失效。
- 确认时重新校验参数摘要，防篡改。
- 过期令牌有明确拒绝提示。

## 错误处理

- 每个失败路径要么抛异常要么返回错误码。
- 没有空的 catch 块。
- 外部调用有超时。
- 错误信息不含密钥与内网地址。

## 状态

- 状态读写集中在一处。
- 金额变动有事务性，不会出现扣了钱没记账。
- 并发写不会互相覆盖（至少用文件锁或串行队列）。

## 审计

- 每次决策一条记录。
- 每条记录带前序哈希。
- 链校验能跑，改一条能发现。
- 敏感字段脱敏。

## 依赖

- 没有新增未说明用途的依赖。
- 依赖版本固定，不用 `*` 或 `latest`。
- 没有引入需要编译工具链的重量级包。

## 结论

```
阻断项：__ 条
严重项：__ 条
一般项：__ 条
结论：可发布 / 不可发布
```
