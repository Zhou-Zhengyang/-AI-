# 从这里开始

三步走完，大约二十分钟。走完你手上就有一个能启动、能对话、能演示的骨架。

## 第一步：选一条路线

把 `prompts/01-选择路线.md` 的内容整段复制给 AI 助手（WorkBuddy、Codex、Cursor 都行）。

AI 会问你两个问题，你回答完，它会删除另一条路线，只留下你选的那份。

不想用提示词，也可以手动执行。

```powershell
node scripts/pick-track.mjs pi
```

或

```powershell
node scripts/pick-track.mjs cordis
```

两条路线的差别，一句话：pi 改一处立刻见效，Cordis 分层更清楚但要多花半天理解。

三天时间，建议 pi。

## 第二步：装环境

按 `docs/06-零基础装环境.md` 走。里面写了 Windows 与 macOS 两种系统，以及国内网络下的镜像配置。

装完用两条命令验证。

```powershell
node -v
npm -v
```

第一条输出 `v22` 或更高，第二条输出 `10` 或更高，就算装好。

## 第三步：跑起来

```powershell
node scripts/check.mjs
```

这一步检查文件齐不齐、有没有把密钥写进代码。全绿再往下。

```powershell
cd track-pi
npm start
```

浏览器打开 `http://127.0.0.1:18150`，输入「查一下余额」。

看到余额和绿色判定，说明骨架跑通了。

## 接下来做什么

打开 `docs/02-三天怎么排.md`，按天推进。

打开 `AGENTS.md`，把里面的规范告诉你的 AI 助手，让它按同一套规矩帮你写。

遇到卡住的地方，先看 `docs/05-常见坑.md`。
