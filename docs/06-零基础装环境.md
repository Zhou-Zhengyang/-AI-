# 零基础装环境

假设你的电脑上什么都没装。这篇从零开始，Windows 与 macOS 分开写，每一步都有验证命令。

## 需要装什么

只有两样：Node.js 与 Git。

| 软件 | 用途 | 版本要求 |
|---|---|---|
| Node.js | 运行时代码与前端构建 | 22 或更高 |
| Git | 版本管理，提交作品要用 | 2.30 或更高 |

不需要装数据库，不需要装 Docker，不需要装 Python。

## Windows

### 安装 Node.js

方法一，官网安装包，最稳。

打开 `https://nodejs.org/zh-cn`，下载 LTS 版本（22 或更高）的 `.msi`，双击下一步到底。

方法二，用 winget，一条命令。

```powershell
winget install OpenJS.NodeJS.LTS
```

装完关掉所有终端窗口，重新打开一个，验证。

```powershell
node -v
npm -v
```

没有输出而是报「无法将 node 识别为 cmdlet」，说明路径没生效。重启电脑再来一次。

### 安装 Git

```powershell
winget install Git.Git
```

或者打开 `https://git-scm.com/download/win` 下载安装包，一路下一步。

验证。

```powershell
git --version
```

### 配置国内镜像

国内直连 npm 官方源经常超时或很慢。换成国内镜像，命令只跑一次，之后一直生效。

```powershell
npm config set registry https://registry.npmmirror.com
npm config get registry
```

第二条命令输出 `https://registry.npmmirror.com`，说明换好了。

如果单位或学校网络有代理，再补一条。

```powershell
npm config set proxy http://127.0.0.1:7890
npm config set https-proxy http://127.0.0.1:7890
```

把端口换成你自己的代理端口。不需要代理时用 `npm config delete proxy` 删掉。

### PowerShell 常见拦截

执行脚本时报「无法加载文件，因为在此系统上禁止运行脚本」，运行这一条。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

输入 `Y` 确认。这条只影响当前用户，不动系统全局设置。

## macOS

### 安装 Node.js

方法一，Homebrew，最省事。

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node
```

Homebrew 官方脚本在国内可能很慢，换镜像。

```bash
/bin/bash -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"
```

方法二，官网安装包：`https://nodejs.org/zh-cn` 下载 `.pkg`，双击安装。

验证。

```bash
node -v
npm -v
```

### 安装 Git

```bash
xcode-select --install
```

弹窗点安装，等几分钟。验证 `git --version`。

### 配置国内镜像

```bash
npm config set registry https://registry.npmmirror.com
npm config get registry
```

## 国内网络下最常卡的三处

### 一、npm install 卡住不动

现象：命令行停在 `sill idealTree buildDeps` 或长时间无输出。

原因：还在走官方源。

处理：确认镜像已切，再清一次缓存。

```powershell
npm config get registry
npm cache clean --force
npm install
```

### 二、下载 Node 安装包很慢

用国内镜像下载站。

```
https://npmmirror.com/mirrors/node/
```

挑对应系统的安装包，Windows 选 `.msi`，macOS 选 `.pkg`。

### 三、装完依赖但启动报找不到模块

现象：`Cannot find module 'xxx'`。

原因：在错误的目录里执行命令。

处理：确认当前目录下有 `package.json`。

```powershell
ls
```

看到 `package.json` 再执行 `npm install`。

## 验证环境是否就绪

在启动包根目录跑。

```powershell
node scripts/check.mjs
```

输出「结构自检通过」就说明环境没问题。

再跑一次冒烟，它会启动两条路线各发四条消息。

```powershell
node scripts/smoke.mjs
```

输出「冒烟通过，两条路线可用」就彻底没问题了。

## 只用网页版也行

实在装不上 Node，可以用 GitHub Codespaces 或阿里云 Cloud Studio，浏览器里开一个带 Node 的环境，把仓库传上去。

代价是每次打开慢一些，好处是零安装。

这条路只建议当兜底方案，因为答辩时需要现场演示，网络不稳会很难受。
