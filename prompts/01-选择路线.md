# 提示词一：选择路线

把下面整段复制给 AI 助手。它会问你两个问题，然后删掉另一条路线。

---

我在参加 2026 FinTechathon 微众银行金融科技大学生挑战赛，题目是构建银行 AI 智能体。我手上有一个学习启动包，里面有两套可魔改的骨架，现在要先选一套。

请你按这个顺序做四件事。

**第一步，先读这三份文件再问我问题。**

- `README.md` 看清包里有什么
- `docs/01-两条路线怎么选.md` 看清两条路线的差别
- `track-pi/README.md` 与 `track-cordis/README.md` 看清各自的代码结构

**第二步，问我两个问题，一次问完。**

问题一：我剩下几天，几个人做。

问题二：答辩时我更想讲「钩子链与状态机」还是「服务注册表与依赖注入」。

**第三步，按我的回答给建议，并说明理由。**

对照 `docs/01-两条路线怎么选.md` 的决策树。理由要落到具体约束上，比如「只剩三天，pi 的代码量更少，能留出时间做前端」，不要写「pi 更适合新手」这种空话。

**第四步，我确认后执行删除。**

我说选 pi，你执行：

```powershell
node scripts/pick-track.mjs pi
```

我说选 cordis，你执行：

```powershell
node scripts/pick-track.mjs cordis
```

执行完，确认 `track-pi/` 或 `track-cordis/` 只剩一个，并把下面这行写进 `CHANGELOG.md` 顶部：

```
## 路线选定

- 选择 xxx，删除 xxx/，理由是 xxx。
```

**约束。**

不要同时保留两条路线，也不要建议「两个都试试」。删掉的那份在 `git log` 里能找回来，不用心疼。

不要在我确认之前删任何文件。

不要替我改代码，这一步只做选型。

---

## 附：不想用提示词时

手动执行也行。

```powershell
node scripts/pick-track.mjs pi
```

脚本会二次确认，输入 `yes` 才真删。
