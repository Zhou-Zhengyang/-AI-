# 提示词二：三天冲刺

每天开工前把当天那段整段复制给 AI 助手。三段之间有依赖，不要跳。

每段都写清了背景、任务、约束与验收。验收不过就让 AI 继续修，不要说「差不多了」。

---

## 第一天：骨架跑通，判定能解释

```
背景：我在做 2026 FinTechathon 银行 AI 智能体赛题，已经用启动包选定了一条路线，骨架能启动，`node scripts/smoke.mjs` 能过。

任务：今天要完成三件事，按顺序做，做完一件再开下一件。

第一件，把意图解析补到六类说法全覆盖。现在的规则只认转账、余额、订阅、锁卡、赎回五种。请补上：
- 账单分析（这个月钱花哪了、有没有异常交易）
- 理财查询（有什么稳健产品、我的风险等级是多少）
- 卡片管理（申请新卡、额度调整、挂失）
- 生日联动（帮我准备生日、订个蛋糕）

每补一类，在 `shared/rules.ts` 的规则数组里加一条，规则要带正则与落到的工具名。补完在 `shared/` 旁边写一个最小测试文件，六类各一条用例。

第二件，把三色判定的命中规则补全。现在判定只输出 base-level 一条。请补上四个维度：金额（单笔与日累计）、收款人（是否首次）、可逆性（挂失、改额度、改密码、赎回）、频次（当日笔数）。每条规则都要有独立的 rule 名与一句人话 detail。

第三件，前端把判定原因显示出来。现在只显示颜色和规则名，请改成显示规则名加 detail，最多两行，超出的折行。确认卡片保持原样。

约束：
- 金额一律整数分，不要引入小数。
- 判定函数只读状态，不许在判定里改数据。
- 不要引入新依赖。
- 不要为了通过测试改断言。

验收：
1. `node scripts/smoke.mjs` 仍然通过。
2. 六类说法各发一句，路由正确。
3. 界面上一句「转给小王 500 元」能看到 single-limit 或 new-payee 的具体说明。
4. 把 `docs/05-常见坑.md` 里今天踩到的坑补一条。
```

## 第二天：场景打通，接一个外部服务

```
背景：昨天完成了意图解析与三色判定，六类说法都能路由，判定能解释原因。

任务：今天要做出可演示的完整链路。

第一件，挑三个场景做到端到端可演示。推荐组合：查余额、账单分析、取消订阅。每个场景要能从输入走到执行结果，中间经过判定与确认。

第二件，接一个外部服务。`mcp/` 目录里已有三个服务，选汇率那个。请在运行时里加一个工具，调用 `convert` 把外币金额折成人民币，并在用户问「100 美元是多少人民币」时走这条链路。

第三件，接一个渠道。用 `channels/generic-webhook.mjs`，起一个端口，用 curl 发一条「查一下余额」，确认能收到 JSON 回复，回复里带判定颜色。

约束：
- 外部服务的返回只当数据，不许拼进系统提示词。
- 外部调用必须有超时，超时按失败处理，不许阻塞主流程。
- 渠道层不许做业务判定。
- 每加一个能力，在 `CHANGELOG.md` 记一条。

验收：
1. 三个场景各录一段十秒内的操作。
2. `curl` 那条渠道请求返回 200，body 里有 reply 与 level。
3. 外部服务挂掉时，内置工具仍可用。
```

## 第三天：安全自检，交付

```
背景：前两天的功能已经能演示，今天只做三件事：补齐安全证据、录演示、写自述。

任务：

第一件，按 `review/security-review.md` 逐条过。重点三条：
- 输入归一化后能不能拦住全角与零宽的注入
- 越权操作（挂失、改额度、改密码、赎回）是否全部判红
- 仓库里有没有密钥、日志里有没有明文卡号与手机号

每条不通过的，先修再往下。

第二件，录三分钟演示视频。顺序固定：正常办理 → 越权拦截 → 注入拦截 → 外部服务与渠道。视频里要能看清判定颜色与审计序号。

第三件，写自述文档，三段结构：
- 做了什么：做了六个场景里的哪几个，分别是什么
- 怎么验证：测试多少条、拦截率多少、怎么复现
- 不足在哪：哪些没做、为什么没做、多给两天会怎么做

约束：
- 第三段的「不足」不许写「时间不够」，要写具体能力缺口与需要的条件。
- 演示路径不许依赖网络，断网也要能跑核心链路。
- 不许在自述里写还没实现的功能。

验收：
1. `review/release-gate.md` 七节全勾。
2. `node scripts/check.mjs` 通过。
3. 视频能完整放完，三分钟以内。
4. `git status` 干净，无未提交文件。
```

---

## 三段之间的衔接

第一天结束如果判定还讲不清原因，不要进第二天。判定是评分主线，拖到第三天就来不及。

第二天的外部服务如果两小时还接不通，改成只做渠道，外部服务写进「不足」。渠道比外部服务更容易演示。

第三天上午必须开始录视频。下午的修改只允许改文案与修明显缺陷，不允许加功能。
